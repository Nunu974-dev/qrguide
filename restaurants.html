Un QR code sur chaque table : vos clients scannent et voient votre menu du jour. Vous le modifiez en 30 secondes depuis votre back-office.

Comment ça fonctionne

Trois étapes, aucune application à installer

1

Le QR code sur la table

Vous recevez un QR code à votre nom (chevalet, sticker ou plaque). Le même code reste valable à vie.

2

Le client scanne

Il ouvre votre menu directement sur son téléphone : entrées, plats, desserts, boissons, allergènes et plat du jour.

3

Vous gérez depuis le back-office

Nouveau menu chaque jour ou chaque semaine ? Vous modifiez, vous publiez : le QR code affiche immédiatement la nouvelle carte.

Essayez : modifiez le menu, le téléphone se met à jour

À gauche, le back-office du restaurateur. À droite, ce que voit le client après avoir scanné le QR code.
